## 性能实验

生产对照使用相同模型、输入、设备、分片策略及统计频率，分别运行关闭监控、旧版 GradientHealthMonitor、新版回调。每组预热后记录普通步、轻步、重步耗时和各 rank 的峰值显存，另统计完整 200 步周期耗时。仅比较平均值会掩盖重步峰值。

v1.0.0 的单线程 CPU 合成实验使用四个宽度为 256 的线性层，各运行 220 步。启用 CSV 采集后，普通步约 0.90 ms，轻步约 60.0 ms，重步约 63.9 ms；关闭时三类步约 0.85～0.86 ms。两个独立进程的峰值 RSS 相差约 10.1 MiB。该试验仅含一个重步。Ascend 910B、HCCL 和生产训练回调的开销待实测。
