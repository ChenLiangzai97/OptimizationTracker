跨步占用 · 保存方向

梯度、一阶矩、二阶矩各留上一统计步的本地分片。三个对象均为 FP32 时，每个受监控的本地元素共需约 12 字节历史快照。旧 TB Hook 的快照另计。

当步峰值 · 算分位数

层跨多卡时，持有最多元素的 rank 临时收齐该层当前对象，再排序求全量分位数。cosine 走另一条路径，只归约各卡的点积和平方和。最大单层和排序工作区影响峰值显存。
